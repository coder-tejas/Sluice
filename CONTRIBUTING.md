# Contributing to Sluice

Status: scaffold — process details land as development begins.

- One service per pull request where possible.
- Conventional commits (`feat:`, `fix:`, `docs:`, `infra:`).
- Docs live with code (`docs/`, per-service `README.md`, ADRs for decisions).
- Never commit secrets; placeholders only (see `.env.example`).
- Local validation: `make lint` and `make test` before pushing.
